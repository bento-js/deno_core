# deno_core (Bento)

`deno_core` as published on crates.io, plus the patches Bento needs. Each upstream version is imported unmodified as its own commit; Bento's changes sit on top as separate commits and are described in [PATCHES.md](PATCHES.md).

Upstream development happens in the [denoland/deno](https://github.com/denoland/deno) monorepo under `libs/core`. Licensed MIT; see [LICENSE.md](LICENSE.md).
